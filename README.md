
# CAR MANAGER

## Descripcion
CAR MANAGER es un programa de consola desarrollado en C# para simular la venta de vehiculos en un concesionario.

## Funciones principales
- Venta de coches de segunda mano, seminuevos y nuevos.
- Seleccion de extras.
- Entrega del vehiculo.
- Aplicacion de descuentos.
- Pago y ticket de compra.
- Consulta de caja y estadisticas.

## Tecnologias utilizadas
- C#
- .NET
- Visual Studio Code
- Git y GitHub
- WakaTime

## Como ejecutar el programa
1. Abrir el proyecto en Visual Studio Code.
2. Abrir la terminal.
3. Escribir: dotnet run
